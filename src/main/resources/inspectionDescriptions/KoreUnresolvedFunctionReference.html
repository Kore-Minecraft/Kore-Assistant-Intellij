Reports function("name") commands whose target function is declared nowhere in the project.

The name-only overload always calls <datapack>:name, even from a function declared under another namespace; the function(namespace, name) overload calls exactly what it is given. A missing target is a command Minecraft refuses at run time.

Quick-fixes offer the closest declared name, the namespace the function is actually declared under, swapping the two arguments when they were passed as (name, namespace), or creating the missing function next to the current one.

Namespaces unknown to the project (another pack on the server) and namespaces holding a runtime-built declaration (function("gen_$i")) are never reported.
