Reports calls to a function using macros that miss one of its arguments, and arguments the function never uses.

The macros a function uses are read from macro("x"), eval("x"), $(x) in a string and macros.x, including the project helpers its body calls. A missing argument makes the call fail in-game, and a quick-fix adds every missing one as this["x"] = "". An unused one is most likely a typo, and the quick-fix renames it to the closest missing macro.

Arguments are checked when written inline, nbt { this["x"] = ... }. Arguments read from a storage (arguments = storage("args", "ns"), path = "x") are checked against what the calling function writes to that storage path before the call, only when it writes there at all. Arguments read from an entity or a block are not checked.
