Reports a vanilla id Minecraft does not know, such as item("diamond_swrod"), block("stonee") or EntityTypeArgument("zombi"), and offers the closest existing ids.

Ids are checked against the registries of the Kore version the module depends on (Items, Blocks, EntityTypes, ...), so they match the Minecraft version you target. Kore writes the id as given; Minecraft then drops the recipe, loot table or command using it.

Ids in another namespace than minecraft, and ids built at runtime, are skipped.
