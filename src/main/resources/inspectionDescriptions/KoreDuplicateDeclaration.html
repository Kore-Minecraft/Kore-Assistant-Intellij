Reports Kore declarations that produce the same file in the same datapack: two function("foo") calls, two predicate("x") in different DataPack extensions, and so on.

Kore generates every declaration; when two of them target the same path, the last one generated silently overwrites the others, so one of them never reaches the game.

Declarations whose name is built at runtime (a loop variable, a concatenation) and declarations that cannot be attributed to a datapack are not reported.
