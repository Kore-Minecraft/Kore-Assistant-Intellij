Reports craftingShaped { } recipes Minecraft would reject at load time: more than 3 rows, a row wider than 3 characters, rows of different widths, a pattern character without a matching key(...), and, as a weak warning, a key no row uses.

Kore writes the recipe JSON as given; the error only shows up in the game log, with the recipe silently missing.

Rows and keys built at runtime are skipped.
