Applies the Kore Gradle plugin to the module's build.gradle.kts: adds id("io.github.ayfri.kore") version "<your Kore version>" to the plugins { } block and a kore { mainClass = "..." } block pointing at the file holding the dataPack call, then syncs the project. The diff is shown before anything is written.

Once synced, the run marker on dataPack(...) offers koreRun (build, link into your worlds, /reload over RCON), koreBuild, koreLink and koreReload.
